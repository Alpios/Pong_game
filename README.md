

# 🕹️ Pong Game (Python Turtle)

A simple 2-player Pong game built using Python’s `turtle` module.

---

## 🎮 Features

* Two-player gameplay
* Paddle controls (W/S and Up/Down keys)
* Ball collision and bouncing mechanics
* Score tracking system

---

## ⚙️ Requirements

No external libraries needed (uses built-in `turtle`)

---

## 🚀 How to Run

```bash
python main.py
```

---

## 🎯 Controls

* **Right Paddle** → ↑ (Up), ↓ (Down)
* **Left Paddle** → W (Up), S (Down)

---

## 🧠 How It Works

* Ball moves continuously across the screen
* Bounces off top and bottom walls
* Changes direction when hitting paddles
* Score increases when opponent misses

---

## 📁 Files

* `main.py` → Game loop
* `ball.py` → Ball behavior
* `board_movement.py` → Paddle movement
* `scoreboard.py` → Score display
